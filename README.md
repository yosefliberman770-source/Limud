# סדר הלימוד — My Torah Learning Library

אפליקציה אישית שמראה בדיוק מה ללמוד היום, מזכירה, ושומרת מה כבר למדת **בספרים הפיזיים שלך**.
האפליקציה לא מציגה טקסט של ספרים — היא רק מארגנת ומסמנת.

A personal, offline-first app that shows exactly what to learn, reminds you, and remembers what you already
learned **in your physical seforim**. It never displays the seforim's text.

## מה יש בפנים

| מסך | מה עושים בו |
|---|---|
| **הספריה** | מדף תלת־ממדי עם הספרים האמיתיים שלך. לוחצים על ספר — הוא נשלף, נפתח, ויומן הלימוד מתגלה. |
| **היום** | כל מה שללמוד היום: תורת מנחם (שיחה ומאמר), לקוטי שיחות של השבוע, חת״ת (חומש, תהלים, תניא, היום יום), רמב״ם ג׳ פרקים, דף יומי, רמב״ן. |
| **לוח השנה** | חודש מלא עם תאריך עברי, חגים, חלונות המאמרים, ומה כבר סומן. |
| **התקדמות** | כמה הושלם, מה בפיגור, וקצב נדרש עד כ״ט אלול. |
| **הגדרות** | תזכורות, חוץ לארץ/ארץ ישראל, מיקום (לזמני שבת), גיבוי ושחזור, נגישות. |

חיפוש והיסטוריית סימונים נמצאים תחת "התקדמות".

## התקנה באנדרואיד (Samsung Galaxy S22 Ultra)

1. העתק את הקובץ `seder-halimud-debug.apk` לטלפון (כבל, Google Drive, או שליחה לעצמך).
2. פתח אותו מתוך "הקבצים". אם אנדרואיד שואל — אפשר "התקנה ממקור לא מוכר" לאפליקציית הקבצים.
3. פתח את "סדר הלימוד". בפעם הראשונה אשר **הרשאת התראות**.

> אין צורך באינטרנט. כל הסימונים נשמרים בטלפון.

### הרשאת התראות ושעון מדויק
* אם דחית את ההרשאה: הגדרות → אפליקציות → סדר הלימוד → התראות → אפשר.
* כדי שהתזכורות יגיעו בזמן גם כשהסוללה חסכונית: הגדרות → אפליקציות → סדר הלימוד → סוללה → "ללא הגבלה".
* בטלפונים מסוימים אנדרואיד לא מאפשר שעון מדויק; במקרה כזה תזכורת עלולה להתאחר בדקות ספורות. ההגדרות מציגות אזהרה כשזה קורה.
* **שבת ויום טוב:** ברירת המחדל — תזכורות לא נשלחות מהדלקת נרות עד הבדלה, ומועברות לאחריה. אפשר לשנות (לפני / אחרי / דלג).

## גיבוי (חשוב!)

הגדרות → **גיבוי ושחזור** → "יצוא גיבוי". נשמר קובץ אחד עם כל הסימונים, ההערות וההגדרות.
כדי לשחזר: "שחזור מקובץ" ובחר **מיזוג** (לא מוחק כלום) או **החלפה מלאה**.
כדאי לגבות פעם בשבוע ולשלוח לעצמך את הקובץ.

## עדכון האפליקציה

התקן את קובץ ה־APK החדש מעל הישן — הסימונים נשמרים. (אם התקנה נכשלת, קודם עשה גיבוי.)

## אם משהו לא נראה נכון

* **הספרים לא נראים תלת־ממדיים / האפליקציה איטית:** הגדרות → איכות הספריה → "חסכונית" או "דו־ממד".
* **אני מעדיף בלי אנימציה:** הגדרות → תנועה → "קצרה" או "ללא". בכל מקום אפשר ללחוץ "היום" כדי לדלג ישר לשיעורים.
* **שיחה/מאמר בלי אותיות:** נכנסים ליומן ולוחצים "הזן חלוקה ידנית".

## למפתחים

```bash
npm install
npm run dev            # http://localhost:5173
npm test               # 88+ בדיקות
npm run validate:data  # בדיקת קטלוגים
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug     # APK ב-android/app/build/outputs/apk/debug/
```

* מבנה הקוד, מקורות הנתונים ומה שלא אומת: `docs/VERIFICATION_REPORT.md`
